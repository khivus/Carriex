# Проверка русского и английского перевода

[English](LOCALIZATION.md) | **Русский**

## Выбор и сравнение языков

Откройте боковое меню → **Настройки → Язык** и выберите **English**, **Русский** или **Как в системе**. Выбор применяется сразу и сохраняется после перезапуска. При пересоздании экрана сохраняются текущая категория настроек, выбранный чат и черновик. На Android 13+ тот же язык меняется в **Настройки Android → Приложения → Carriex → Язык**. В более ранних версиях используйте переключатель Carriex. Оба языка включены в APK и app bundle для переключения без сети. Активное подключение при смене языка может кратковременно восстановиться.

По умолчанию используется язык Android. Для неподдерживаемых языков действует английский. Переключение не переводит имена контактов/серверов/групп, тексты сообщений, ID, отпечатки, поля протокола, URL, JSON, CSV и значения технической диагностики. Известные ошибки проверки, безопасности и транспорта имеют русские ресурсы; неизвестные ошибки ОС/библиотеки/сервера показываются с русской подписью **Технические сведения** и исходным текстом. Системные разрешения, настройки Android и клавиатура также зависят от языка ОС и поставщика.

Для точного сравнения сохраняйте устройство, тему, масштаб экрана/шрифта, сервер и данные. Выберите English, сделайте снимок, переключите на русский и повторите действие. Не очищайте данные: это уничтожает идентичность установки и историю. Переустановка для смены языка не нужна.

## Отчёт с поиском по текстам и документации

Из репозитория Android, с Python 3.10+:

```powershell
python tools/check_localization.py --report build/localization-review.html
Start-Process build/localization-review.html
```

Отчёт работает без сервера и интернета. В каждой строке — ключ ресурса, английский и русский рядом. Поиск работает по обоим языкам и ключу. Разверните **Documentation comparison**, чтобы читать полные исходники Markdown параллельно. Если существует соседний `../Carriex-server`, он добавляется автоматически. У каждого документа также есть ссылка на другой язык; русские версии называются `.ru.md`, английские оригиналы сохранены.

Проверка завершается с ненулевым кодом при встроенном в исходники интерфейса чатов тексте, отсутствии/пустоте/неизменённости перевода, повторе ключа, несовпадении позиционных параметров или их типов, отсутствии русских форм множественного числа, отсутствующей русской документации, изменении команд/протокольных примеров в блоках кода, неверных локальных ссылках и изменении английского документа после проверки перевода. После ручного обновления и проверки переводов выполните `python tools/check_localization.py --stamp-docs`, чтобы записать новую ревизию английского источника. Проверка оценивает структуру, а не качество языка и все визуальные состояния. Позиционные параметры можно переставлять. Общие бренды и названия языков помечены `translatable="false"`; машинные идентификаторы намеренно неизменны. Негативные тесты самой проверки запускаются командой `python -m unittest discover -s tools`.

Английские ресурсы редактируются в `app/src/main/res/values`, русские — в `values-ru`. Интерфейс использует `getString` и Android plurals. Не переводите стабильные ID разделов, значения протокола и хранилища. `localization/ErrorResources.kt` перечисляет существующие ошибки логики и отмечает только диагностические аргументы для вложенного перевода; имена контактов/групп/серверов остаются непрозрачными данными. При смене английской ошибки меняйте ресурс и запись адаптера вместе. Для интервалов используйте `LocalizedFormat.interval`; ввод принимает точку и запятую.

## Сборка и проверки на устройстве

Нужны Android SDK и совместимый JDK:

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
.\gradlew.bat :app:connectedDebugAndroidTest '-Pandroid.testInstrumentationRunnerArguments.class=com.example.carriex.localization.LocalizationAndroidTest'
python tools/export_localization_screenshots.py
Start-Process build/localization-screenshots/index.html
```

В PowerShell заключайте весь аргумент Gradle `-P...` в кавычки. Выделенный инструментальный класс проверяет каждый ресурс диагностики в обоих языках, вложенные ошибки с сохранением имени `Blue`, целые/дробные интервалы, формы 1/2/5/11/21/22/25/101, уведомления с количеством, десятичную запятую, смену языка и сохранение страницы при пересоздании. Он создаёт парные снимки настроек, настроек чатов, конфиденциальности и оформления. Скрипт экспорта читает только эти снимки отладочного приложения; при нескольких устройствах задавайте `--serial`. Результаты остаются в игнорируемом `build/`.

APK: `app/build/outputs/apk/debug/app-debug.apk`. Отчёты инструментальных и unit-тестов — в `app/build/reports`. Языковой тест восстанавливает прежний язык. Запускайте на эмуляторе/тестовом устройстве: другие интеграционные тесты приложения могут создавать или сбрасывать собственные тестовые данные.

## Ручная приёмочная проверка

Подключите две тестовые установки к одному обновлённому серверу. На одной оставьте английский, на другой — русский, затем поменяйте роли.

| Раздел | Что сравнить |
|---|---|
| Меню и навигация | Мой ID, Чаты, Серверы, Настройки; Назад, заголовки, меню и описания плавающих кнопок для доступности |
| Добавление сервера | Подсказка/отмена сканера, импорт текста, неверный JSON, проверка/сохранение, отпечаток, подключение/отмена/отключение, автоподключение, сведения/удаление, история без сети |
| ID и контакты | Собственный QR, копирование/отправка, полный/короткий ID, локальные имена, переименование/очистка, совпадение/несовпадение/собственный ID, значок проверки, подтверждения удаления/блокировки/нового сеанса |
| Настройки | Все категории, темы/акценты/цвета, проверка hex/пример, цвета участников и сохранение; отдельно меняйте язык и тему |
| Запросы | Ноль/один/много запросов и приглашений, принятие/повтор/удаление/блокировка, вступление/отклонение, просмотр без подключения и прогресс |
| Группы | Создание/переименование/приглашение текстом, контактом, QR; участники/администратор/приглашённые, локальные имена, отзыв/удаление/выход/закрытие; подписанные события и история |
| Чат | Пустой чат, кириллица/латиница/эмодзи/переносы, длинные имена, сегодняшние/старые даты, Отправка/Отправлено/Получено/Прочитано/Срок истёк/Ошибка, доступность времени; прокрутка, фокус и черновик |
| Уведомления | Независимые запросы/приглашения, счётчики, имена/описания каналов, постоянное уведомление и остановка, единицы/ошибки интервала, разрешения, батарея, последние проверки/ошибки |
| Ошибки | Некорректные ID/подключение/цвет/интервал, недоступность, TLS/смена ключа, нехватка одноразовых ключей, карантин и обновление защиты группы |

Проверьте узкий портретный экран, альбомный режим, светлую/тёмную темы и увеличенный шрифт, например 1,3× и 2×. Подписи должны переноситься без скрытия действий; не должно быть наложений, обрезки и прыгающего времени. Проверьте TalkBack. Английскую грамматику тоже проверяйте: русский текст часто длиннее. Для чисел используйте 0, 1, 2, 5, 11, 21, 22, 25, 101 и 1,5 секунды.

Равенство каталогов не заменяет просмотр экранов. Камера/разрешения физического телефона, фоновые ограничения производителя, сохранение языка на Android 7–12 и реальные ошибки/доставка между двумя телефонами требуют отдельной проверки сверх выделенного теста эмулятора.

## Страницы сервера и документация

Откройте созданный `pairing.html` и локальную статистику (`python -m src.statistics serve`). Обе страницы имеют **Language / Язык**, исходно по языку браузера. Сохранённый выбор приоритетнее; `?lang=en` или `?lang=ru` принудительно задаёт начальный язык для сравнения. Страница подключения работает без сети с `pairing.png` рядом и содержит переводы внутри. После смены настроек сервера обновляйте экспортированные файлы.

Сравните заголовки, инструкции, описания изображений/полей, выбор языка, карточки/пустое состояние/ошибки статистики, формат чисел и обновление после переключения. Имя сервера и JSON подключения должны оставаться целыми. Идентификаторы показателей, данные UTC и экспорт JSON/CSV стабильны для воспроизводимых измерений. Вывод терминала/CLI — диагностический интерфейс разработчика/оператора и остаётся английским; русские инструкции объясняют те же команды.

Не меняйте архивные Kotlin/TLS-снимки ради текущего интерфейса: они не компилируются. Их русская документация явно помечает историческую схему.
