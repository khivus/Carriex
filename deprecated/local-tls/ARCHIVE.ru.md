# Архивная реализация локального TLS

[English](ARCHIVE.md) | **Русский**

Удалена из активного приложения по просьбе пользователя: подготовка локального CA и импорт сертификатов слишком усложняли подключение Docker и телефонов.

Здесь сохранены полные версии затронутых клиентских исходников той эпохи, валидатор CA, localhost TLS-тесты и инструкции. Они вне наборов исходников Gradle и не компилируются в APK. Соответствующий серверный вариант сохранён в `D:/Git/Carriex-server/deprecated/local-tls/`.

Историческое состояние после удаления этой реализации использовало HTTP и порт 5000 по умолчанию, сохраняя прежний необязательный HTTPS для сертификатов, доверенных Android, без импорта своего CA. Существующие настройки подключения сохранялись. Это описание архивного этапа, а не текущего приложения с QR-подключением и прямым TLS; актуальные инструкции — в [основном README](../../README.ru.md).

Для возврата к реализации переносите нужные изменения из снимков в актуальные исходники и восстанавливайте соответствующую серверную схему. Не перезаписывайте новые исходники старыми целиком. Архивный README описывает прежнее поведение.
