# Carriex для Android — архив

[English](README.md) | **Русский**

Исторические инструкции. Текущее приложение описано в [основном README](../../README.ru.md).

## Подключение и общение

1. Откройте приложение, введите домен/IP и порт сервера Carriex без схемы URL и пути. По умолчанию HTTPS и 443; сохранённые настройки остаются. На эмуляторе `10.0.2.2` обращается к компьютеру, физическому телефону нужен доступный локальный или публичный адрес.
2. Нажмите **Connect** («Подключиться»). Приложение проверяет `/health` до открытия чатов, запоминает адрес/порт.
3. Каждая установка имеет один сгенерированный ID. **Copy my ID** копирует его для передачи собеседнику.
4. На другом устройстве того же сервера выберите **New chat**, введите ID и отправьте сообщение. Входящие беседы появляются автоматически.
5. Нажмите беседу для открытия; **All chats** или Android «Назад» возвращает список. **Server** позволяет отключиться и изменить адрес.

Настройки, собственный ID и контакты сохраняются. Контакты и зашифрованные ключи изолированы по адресу сервера. Сообщения, непрочитанное и черновики переживают поворот экрана только в текущем процессе: отключение/завершение очищает их. Фоновых уведомлений и подтверждений доставки/прочтения в этой версии нет. Появление собственного сообщения не доказывает доставку. Для начального обмена ключами получатель должен подключиться.

Маршруты и формат сервера не изменены. Контакт выбирается по переданному ID; каталога пользователей и аутентификации аккаунтов в этой версии нет.

## Локальный TLS

Используйте серверные `compose.https.yaml` и `HTTPS.md` для Caddy с частным CA в LAN. Введите точный настроенный IP/имя и порт 443. Через **Local server certificate** импортируйте открытый корневой сертификат и непосредственно сверьте SHA-256 с сервером перед одобрением. Доверие сохраняется только для этого HTTPS-адреса и не меняет глобальное хранилище Android.

CA проверяется как действительный самоподписанный центр и используется с системным trust manager. HTTPS и WebSocket сохраняют проверку цепочки и имени узла. Перенаправления отключены; ошибка TLS не вызывает переход к HTTP. Без локального переопределения действует системное доверие. Удаление переопределения возвращает его.

TLS защищает транспорт. Аутентификация пользователя сервера и аутентифицированный обмен ключами собеседников в архивной версии отсутствуют; это ещё не защищённый мессенджер для рабочего использования.

## Проверка

Запустите `./gradlew.bat :app:assembleDebug :app:testDebugUnitTest` с Android SDK и подходящим JDK. Тесты проверяют домены/IP/IPv6, границы портов, неверные адреса и ID получателя.

На двух установках одного сервера обменяйтесь ID и сообщениями в обе стороны, добавьте третью беседу для маршрутизации, поверните экран с черновиком и повторно откройте приложение для проверки настроек/контактов. Проверьте неверный/недоступный адрес и размеры при показе клавиатуры.
